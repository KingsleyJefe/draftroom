# RM Studio React TS template

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules by RM Studios.

This template has the following set up:

- Axios instance and interceptors
- React Query for state management
- React Router for routing
- Tailwindcss for styling
- Sonner for popup notifications
- Gsap and framer motion for animations
- Lenis for smooth scroll

Do remember to add .env to the .gitignore file after cloning.
